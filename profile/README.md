## 我们做了以下项目 · Projects we've built

- [genius-invokation-simulation](https://github.com/Fontaine-Research-Institute/genius-invokation-simulation) —— 模拟器与规则引擎：对局模拟、规则引擎、精确概率 · simulator and rules engine

## 做什么 · What we do

- **对局模拟**：可复现的对局模拟与规则引擎 · Reproducible match simulation and a rules engine
- **精确概率**：以精确分数（不是浮点）做多回合决策与概率分析 · Exact-fraction multi-turn decisions and probability analysis
- **规则落地**：把规则书条款变成可执行、可测试的类型与函数 · Turning the rulebook into executable, testable types and functions

## 取向 · Principles

- Rust；不引入不必要的依赖 · no unnecessary dependencies
- 概率用精确分数，不采样、不用浮点 · probabilities are exact fractions — no sampling, no floats
- 数据只有一份；纯函数优先；一切可测试 · single source of truth; pure functions; everything testable
